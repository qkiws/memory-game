# Memory Game

Игра Memory Game на поиск пар.

Игрок открывает карточки и ищет одинаковые пары. Всего на игровом поле находится 16 карточек — 8 пар.

## Возможности

* 16 карточек и 8 пар;
* случайное перемешивание карточек;
* подсчёт ходов;
* подсчёт найденных пар;
* автоматическое закрытие несовпавших карточек;
* кнопка «Новая игра»;
* окно победы;
* таблица лидеров;
* сохранение результатов в `localStorage`.

## Технологии

* HTML
* CSS
* JavaScript
* localStorage

## Запуск

1. Клонировать репозиторий:

```bash
git clone <ссылка-на-твой-репозиторий>
```

2. Перейти в папку проекта:

```bash
cd memory-game
```

3. Открыть файл `index.html` в браузере.

Также проект можно запустить через расширение Live Server в Visual Studio Code.
